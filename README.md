# Personal Portfolio Website

A responsive personal portfolio website built with HTML and CSS, presenting my projects, education, technical skills, certifications, and professional contact links.

## About

I'm Sana Ullah Khan, a BS Computer Science student at the National University of Pakistan. This portfolio brings my work and background together in one place.

## Features

- Clean, responsive layout that works on desktop and mobile
- Projects section with short descriptions and links
- Education and certifications
- Technical skills overview
- Contact and social links

## Built With

- HTML5
- CSS3

## Sections

- **Home**: introduction
- **Projects**: selected work
- **Education**: academic background
- **Skills**: technical skills
- **Certifications**: completed courses
- **Contact**: how to reach me

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/[sanaullah837]/[portfolio].git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
